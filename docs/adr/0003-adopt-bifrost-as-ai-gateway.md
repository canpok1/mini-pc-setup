# 0003. AI の呼び出しを Bifrost に集約する

- ステータス: 採用
- 日付: 2026-10-12

## コンテキスト

plant-diary・trading-studio は AI（Gemini など）を呼ぶ。API キーをアプリごとに持たせると、差し替えや使用量の把握がアプリの数だけ要る。

## 決定

AI ゲートウェイ Bifrost（`maximhq/bifrost`）を置き、アプリの AI 呼び出しはすべて経由させる。

- 本物のキーは Bifrost の管理画面で登録し、アプリには仮想キーだけを渡す
- アプリとは Docker ネットワーク `ai` でつなぐ（`http://bifrost:8080`）
- 管理画面は Tailscale Serve で tailnet 内にだけ出す
- 管理画面のパスワード保護と、仮想キーの無い推論の拒否を有効にする。`ai` からは管理 API にも届くため
- 保存するキーは `BIFROST_ENCRYPTION_KEY` で暗号化する。暗号化キーは `data/` の外に置き、バックアップにキーを平文で残さない
- バージョンを固定し、watchtower の対象にしない

## 結果

- 本物のキーが1か所にまとまり、アプリごとに予算・回数制限を付けられる
- アプリは呼び先を Bifrost に変える改修が要る
- 暗号化キーを失うと登録したキーが読めなくなる

## 検討した代替案

- **アプリごとにキーを持たせる（現状）**: 上記の手間が残るため却下
- **Vaultwarden で保管する**: 人が見る保管庫で、アプリへの配布に別の仕組みが要るため却下
